## Notes

- **cpython**: Upstream run_tests.sh drives 'make test' from a wasm build tree (build-wasm/); replaced by stdlib smoke tests.
- **gcc**: Needs network access once: contrib/download_prerequisites fetches GMP/MPFR/MPC.
- **llvm-project**: Very large binaries; the rewriter (gsfork-elf) may hit its per-tool timeout.
- **openblas**: Built with NOFORTRAN=1 USE_THREAD=0 TARGET=GENERIC: no gfortran in the dev image, and the HASWELL kernels use AVX (vmovupd), which gsfork-elf rejects.
- **openssl**: Built no-asm, like compile_openssl.sh. With OpenSSL's default x86-64 assembly, gsfork-elf rejects the AVX-512 paths (unsupported instruction vpxord).
- **postgres**: Client tools link libpq statically. Server-side extensions (plpgsql, dict_snowball, ...) are shared objects loaded with dlopen and are installed unrewritten.
- **tinycc**: Upstream run_tests.sh targets i386 (wasm build) and needs sudo + an i686 cross toolchain; replaced by smoke tests.
